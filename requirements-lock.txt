# requirements-lock.txt -- pinned, transitive-closure dependency lock.
#
# Generated from a known-good `.venv\` via `pip freeze`.  Every package
# the runtime touches is pinned to an exact version so a compromised
# transitive dependency on PyPI cannot be silently picked up by a fresh
# install.  Use this file in preference to `requirements.txt` whenever
# possible -- `requirements.txt` is the human-curated top-level list,
# this lock is what gets installed.
#
# To refresh:
#   1. .venv\Scripts\pip install -r requirements.txt   (resolve fresh)
#   2. .venv\Scripts\pip freeze > requirements-lock.txt
#   3. Diff vs. previous lock; spot-check any unexpected version jumps.
#   4. Commit.
#
# Notes:
#   - torch / torchaudio carry a `+cpu` local-version label because they
#     come from https://download.pytorch.org/whl/cpu.  setup.bat passes
#     that index URL when installing torch, so the lock resolves cleanly.
#   - pyinstaller + altgraph + pefile + pywin32-ctypes are only needed
#     to build the installer; they are harmless on a runtime install.
#   - pytest + iniconfig + pluggy come from requirements-dev.txt and are
#     pinned here for reproducibility but unused at runtime.
# =====================================================================
